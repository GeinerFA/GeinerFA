## Proyecto destacado

### Pura Vida Interculturas

Plataforma web **Full Stack** desarrollada para digitalizar y administrar diferentes procesos de Pura Vida Interculturas.

La solución integra un sitio web público con un panel administrativo para la gestión centralizada de información.

### Funcionalidades principales

- Sitio web público
- Panel administrativo
- Gestión de programas
- Gestión y seguimiento de solicitudes
- Administración de usuarios
- Roles y permisos
- Gestión de contenido
- Formularios protegidos mediante reCAPTCHA
- Registro de actividad y auditoría
- Gestión de contenido multimedia
- Despliegue web
